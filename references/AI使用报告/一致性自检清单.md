# AI 使用报告：一致性自检清单

每项必须给出"核对结果 + 证据位置"；存在 FAIL 不得提交用户审核。

## 一、论文声明 ↔ 报告

- [ ] 论文中「AI 工具使用声明」位于参考文献之前（不是之后），版式与官方模板一致
- [ ] 声明为官方固定文案二选一；使用版文案除【简要用途】外未改字
- [ ] 声明"使用了 AI 工具"且报告 1.1 勾选"使用"，两者互相一致
- [ ] 若 `ai_usage_log.md` 存在使用记录，论文声明未出现"未使用任何 AI 工具"
- [ ] 声明的【简要用途】与报告 1.3 综述、工具清单一句话用途无冲突

## 二、留痕 ↔ 报告

- [ ] `ai_usage_log.md` 覆盖第 1–11 部分实际推进的所有 AI 参与环节；无"有使用却漏记"
- [ ] 报告中每个"使用"环节都能在留痕找到对应行
- [ ] 报告时间（日期/时段）与留痕一致；正式竞赛报告中无赛前练习时间混入
- [ ] 工具名称与版本：留痕、工具清单、分环节记录三处完全一致
- [ ] 提示词摘要在留痕与典型交互中一致（摘录版 vs 概括版不冲突）
- [ ] 报告中"采纳/修改/弃用/重跑"与留痕处置一致
- [ ] 留痕里 AI 参与过建模候选/初稿时，报告未把该环节写成"未使用"或"模型完全独立推导"

## 三、报告内部各表互相一致

- [ ] 1.1 是否使用与一、声明勾选一致
- [ ] 1.2 使用环节总表与第二部分各环节记录逐行一致（是否使用、工具、时间）
- [ ] 第二部分未使用环节与第四部分"独立完成"勾选不冲突
- [ ] 第三部分典型交互示例所属环节与第二部分记录一致，无"示例在但记录未使用"或反之
- [ ] 4.1 事项勾选与第二部分记录一致（AI 参与过的实现/预处理/绘图/写作项标"否/辅助"并写说明）
- [ ] 1.3 综述与 4.2 综述口径一致（均为"参赛队主导核心建模 + AI 辅助 + 逐项审核"）

## 四、报告 ↔ 论文/代码/附录

- [ ] 每个分环节记录填写的"论文/代码对应位置"真实存在（章节标题、脚本名、结果文件、图表）
- [ ] 报告所说模型/方法名与论文正文一致；摘要提及的关键模型在报告中不缺失
- [ ] 报告所说结果/数值不引用论文没有的数据
- [ ] 论文附录支撑材料文件列表已包含 `AI工具使用详情.pdf`
- [ ] 代码与结果文件时间线能支撑报告声称的使用时段（例如竞赛期间脚本 mtime 与报告一致）
- [ ] `results/复现清单.json` 与报告提到的复现/核验方式一致

## 五、隐私与合规

- [ ] 报告无姓名、学号、学校、赛区等身份信息
- [ ] 无账号、密钥、token、内网地址、家庭/工作地点等敏感信息
- [ ] 无未脱敏的原始对话全文；仅有脱敏摘录
- [ ] 未虚构任何工具、时间、环节、人工动作
- [ ] 练习/模拟运行产生的报告已明确标注"演练"，未冒充正式竞赛记录
