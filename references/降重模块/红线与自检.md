# 保学术性红线与自检（降重专用）

## A. 保护片段（永不改，逐项核销）

- 公式（编号 `(1)(2)…`、符号、上下标）——改后必须 `equations.py verify-formulas` 复验
- 图/表编号与题注、图内文字、图表本体
- 数值与单位、百分比、显著性（p 值）等量化结果
- 参考文献编号与正文引用（`[n]`、`（n）`）、文献条目
- 专业术语、模型名、方法名、算法名、符号说明表
- 标题层级、章节顺序、摘要独立页等官方格式要素
- 摘要内每个数值（与正文必须逐字一致）

完整禁改片段圈法见同目录 `方法库/protected-spans.md`。

## B. 禁止操作

- 口语化、网络用语、情绪词、感叹/反问、破折号堆砌、金句
- 整段 AI 全量重写、同义词轮换
- 编造事实、数据、异常值、文献或“原文没有的观察”
- 为“更像人”把规范被动句改成口语主动句
- 删除限定词导致结论过度绝对；改变结论主张
- 改动符号定义、公式、图表引用、参考文献编号

口语化负面清单与正面句式见 `方法库/replacement-tables.md`、`方法库/positive-style-academic.md`；10 种深度 AI 痕迹见 `方法库/ai-patterns.md`。

## C. 降重后自检清单

- [ ] 每处修改有“原句 → 新句”记录，且未触碰保护片段
- [ ] 学术书面语体保持：无口语化/网络词/情绪词/破折号堆砌/全量重写
- [ ] 复跑 `scripts/aigc_scan.py`：修改率达到目标，口语化/破折号维度无新增命中
- [ ] 复跑 `scripts/paper_check.py` 通过（占位符、公式编号、图号/表号顺序）
- [ ] `equations.py verify-formulas` 通过，无公式转义文本
- [ ] 摘要数值与正文逐字一致；无新增无出处证据
- [ ] 与冻结稿差异仅为措辞；冻结稿哈希保留可回溯
- [ ] 用户审核通过后才交付降重版
