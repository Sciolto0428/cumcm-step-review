# 质检清单

作者自检、用户审核、独立质检三者不能互相替代。以下清单在对应节点逐项核对。

## 一、数据与代码阶段自检

- [ ] 数据读取后检查编码、列名、形状、单位、缺失值和异常值，不在数据错位时继续建模
- [ ] 随机算法固定随机种子，多次独立运行并报告均值与标准差
- [ ] 预测类：划分数据后才 fit scaler/encoder；时序不随机打乱；测试集不参与调参
- [ ] 优化类：先保证可行解，再优化目标；最优解回代全部约束，输出每条约束的值、边界、松弛量
- [ ] scipy 最大化目标已取负并在结果记录中还原真实目标值；不等式约束方向已代入边界点验证
- [ ] 整数变量（人数/车辆/批次/0-1）没有停留在连续解；取整后重新验证可行性
- [ ] 图论/网络类：核对节点数、边数、有向/无向、负权边、连通性和容量
- [ ] 机理/微分方程类：状态变量有物理含义，初始条件、边界条件明确；刚性问题选合适求解器；检查守恒量
- [ ] 中间过程全部落盘（清洗摘要、模型参数、迭代历史、约束检查、图表数据源、运行日志）
- [ ] 结果文件记录了关键参数、核心数值、约束检查、灵敏度和可复现运行方式

## 二、图表自检（每张图）

- [ ] 图内没有任何标题（上方/下方均无），没有面板编号，只保留数据
- [ ] 图题（caption）在图下方；正文先引导、图后紧跟至少一段分析；连续两张以上图表间没有文字判为硬错误
- [ ] 字号按最终印刷尺寸设定（正文标签 8.5–11pt，最小 ≥7.5pt），无图大字小
- [ ] 图型多样性：同类型图全篇不超过 3 张、同类图不连续出现 3 张以上（避免审美疲劳）
- [ ] 配色来自 `JOURNAL_PALETTES`（默认 nature），灰度下可区分，不用颜色作为唯一区分手段
- [ ] 布局按面板数量与证据权重选择，不是默认 2×2；图宽在正文栏宽内
- [ ] 导出默认 300 DPI PNG；SVG/灰度预览按需追加；SVG 存在时文本检查为提示而非 FAIL
- [ ] 误差类图形在图注中写清误差类型（SD/SEM/95%CI/IQR）、样本量 n、检验方法与校正
- [ ] 数据图必须由真实结果数据生成并保留数据源；流程图/架构图不与数据图重复
- [ ] 图中文字、坐标轴、图例与论文语言一致；不写长标题

## 三、论文文本自检（每部分写入草稿前）

- [ ] 已读取 `references/优秀论文写法指南.md` 对应章节（需要实证句模/章节频率时已读取 `references/优秀论文语料分析报告.md` 对应小节），正文符合该部分的国赛优秀论文篇幅、结构、句式与证据组织（对照 `roles/论文手/自审框架.md` 第三节逐项核对）
- [ ] 无占位符：TODO、PLACEHOLDER、待补充、待续写、示例数据
- [ ] 正文不出现内部工作流文件名、临时目录名、脚本名、结果 JSON 路径
- [ ] 摘要/结论中的每个数值与结果记录一致；不换一套四舍五入口径
- [ ] 公式出现后解释符号含义；图表出现前后有引导与解释
- [ ] **公式格式通用检查（所有含公式的部分）**：公式独占一行居中、编号右对齐且连续、正文用（n）引用；Word 实际打开目测 + `paper_check.py` / `equations.py verify-formulas` 检查通过；发现问题已修复并重新提交审核
- [ ] 每问结果分析末尾落到"结果对实际问题的帮助"：回答题目要求是否满足、给出判断/建议、说明结论实际意义（不只报数值）
- [ ] 参考文献真实存在，与正文引用双向对应；中文文献有明确核验判定
- [ ] 章节结构与目标比赛模板一致，标题层级正确
- [ ] 图后必跟分析：每个图/表后都有解读段落
- [ ] 每个部分冻结时已向 `ai_usage_log.md` 追加该环节真实使用记录（环节/时间/工具/提示词摘要/处置/核验/对应文件），未到提交前补记
- [ ] 使用 AI 工具时，论文参考文献之前已写入官方二选一文案的使用版声明，【简要用途】与已冻结内容一致

**摘要专项（第 11 部分，按 `references/摘要写作/摘要写作方法论.md` 两阶段闭环执行）**：

- [ ] 已读取 `references/摘要写作/摘要写作方法论.md`，按"起草 → 二次验证 → 定稿"闭环执行，并输出验证/诊断报告与关键改动说明
- [ ] 逐题段与子问题一一对应、顺序一致；总起段符合"背景→问题→方法"范式
- [ ] 每问都有量化结果（数值+单位），且与正文结果一致（事实核验表：原值→新值对照）
- [ ] 摘要无公式、无表格（参数/数值作行内记号保留）；模型公式一律文字点名
- [ ] 关键词 4–6 个且与正文术语一致
- [ ] 无"较优/较好/大概/非常不错"等无量化词；无照抄题面
- [ ] 改写模式：未新增正文与摘要都没有的证据；数值/模型名/表号与原稿一致（G 组事实保真）
- [ ] 篇幅 300–1000 字（随子问题数伸缩），含标题与关键词不超一页

## 四、用户审核（硬性门禁）

每个部分写入 `论文草稿.docx` 后提交用户审核；未通过不得冻结。用户要求修改时，修改后重新提交审核。已冻结部分发生实质变化时，相关审核立即失效，必须复验。

## 四·一、每问求解审核专项（公式格式 + 模型求解过程，硬性）

适用于第 3 部分每一问（q1→qN）写入 `论文草稿.docx` 后的用户审核；**任一硬项未通过不得进入下一问**。

### 公式格式

- [ ] 每个公式独占一行、居中；编号 `(1)(2)…` 右对齐、全文连续；编号后不加标点
- [ ] 正文引用公式用 `（n）`（LaTeX 用 `\eqref`）
- [ ] 公式出现后解释每个符号的含义
- [ ] Word 草稿实际打开目测：公式在版心正中、编号贴右缘（制表位 4150/8300 等位置正确）
- [ ] LaTeX 源码无 `\[...\]`、`equation*`、`align*`、手写 `\tag`（全部用编号环境）
- [ ] 公式正确输出：无 `EQ_` 占位符残留；`verify-formulas` / `paper_check` 公式检查通过
- [ ] 公式为真实数学对象（Word 原生 OMML / LaTeX 数学环境），正文无 `x\_i`、`$...$` 等 Markdown/LaTeX 转义文本泄漏（`verify-formulas` / `paper_check.py` 检测）

### 模型求解过程（四步骨架）

- [ ] 有 1 句算法选择依据（目标函数凸性/单调性、约束特点、数据规律）
- [ ] 有 1 句算法总述（采用/利用/基于××算法对模型进行求解）
- [ ] 有 Step 式步骤（每步一个动作：加载/计算/判断/更新）或编号算法行
- [ ] 指明求解工具与关键函数、参数设置（如 MATLAB quadprog、Python 遗传算法、种群/迭代参数）
- [ ] 每步末尾有总结语（至此/综上）
- [ ] 结果衔接给出数值 + 对应变量取值（88% 获奖论文做法），可改约束重求对比
- [ ] （加分）收敛/迭代说明、复杂度、随机种子多次运行；配求解流程图

## 四·二、终稿去 AI 味 / AIGC 降重专项（可选，用户要求时执行）

- [ ] 只在全部审核定稿后执行；默认不执行、不改冻结原稿
- [ ] 改写前按 `references/降重模块/红线与自检.md` 圈出保护片段（公式/数值/图题/引用/术语）
- [ ] 逐处“原句→新句”差异记录，未触碰保护片段；无编造事实/数据/文献
- [ ] 学术书面语体保持：无口语化、网络词、情绪词、破折号堆砌、全量重写
- [ ] 摘要数值与正文逐字一致；公式编号、图号/表号连续
- [ ] 复跑门禁：`scripts/paper_check.py`、`equations.py verify-formulas`、`paper_format.validate` 通过
- [ ] 产出 `完整论文-去AI味版.docx/pdf` 与 `降重差异审计.md`；冻结原稿哈希保留
- [ ] 用户审核通过后才交付降重版

## 五、独立质检（可选，默认关闭）

用户明确启用时，在关键节点派未参与编写的 Subagent 复核：

- 建模终检：子问题覆盖、假设依据、公式与符号、单位与约束、模型数量、可实现性、引用可溯源
- 编程终检：独立复现、输入哈希、随机种子、关键数值、边界与量纲、各子问题图表数量与语义、文件完整性
- 论文终检：当届规则、主张—证据、数值与单位、图表引用、文献、实际渲染效果

质检 Subagent 只返回带证据的 PASS/FAIL/BLOCKED（范围、输入快照、证据、发现、返工入口）；存在未解决 P0/P1 只能返回 FAIL；主 Agent 不得把 FAIL 改写成通过。

## 六、最终验收（全部冻结后）

- [ ] Word 分支：原生 OMML、DOCX 结构、转换告警门禁、渲染页数检查；公式编号右对齐且连续
- [ ] LaTeX 分支：环境诊断、真实编译、日志、权威资源—源码—PDF 哈希绑定、页数、空白页、页面尺寸、字体嵌入、图片 DPI；公式编号右对齐且连续
- [ ] 公式正确输出：Word 无 `EQ_` 占位符残留且 OMML 校验通过（`equations.py verify-formulas`）；LaTeX 公式数量与 `eq:` 标签核对一致、编译日志无公式错误；渲染抽检公式无乱码/截断/越界；正文无 `x\_i`/`$...$` 等转义文本泄漏
- [ ] 图号/表号顺序核验（摘要、问题分析、符号说明等后写部分并入后必做）：全文按出现顺序 图1…图N、表1…表N 连续，无缺号/重复/乱序；正文引用与编号一致（DOCX `paper_format.validate` / LaTeX `.aux` 编号 / `paper_check.py` 三重核对）
