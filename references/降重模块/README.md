# 第 13 部分（可选）：终稿去 AI 味 / AIGC 降重版

定位：在全部部分审核定稿、生成最终论文之后，**仅当用户明确要求**“降重 / 去 AI 味 / 降 AIGC / AIGC 查重前准备 / 让论文不像 AI 写的”时才执行的可选项。默认不执行；执行时**不修改冻结原稿**，产出独立的“去 AI 味版”与逐条差异审计。

## 自包含说明（本模块不依赖任何外部 skill）

本模块全部方法、词表、模式库与扫描脚本均已内置：

```text
references/降重模块/
  README.md                        # 本文件：触发、协议、门禁
  红线与自检.md                     # 保护片段 + 禁止操作 + 降重后自检清单
  方法库/
    replacement-tables.md          # 词级/句级/段落级替换表 + 中文 AI 高频词 + 口语化负面清单
    ai-patterns.md                 # 10 种深度 AI 痕迹识别模式
    detection-principles.md        # 知网/万方/PaperPass/PaperPure 检测原理与规避边界
    positive-style-academic.md     # 降重正向标准与“降重不足/过度口语/恰当”三级对照
    protected-spans.md             # 改写前必须圈出的禁改片段
    benchmark.md                   # 双向基准（该改 / 不该误杀 · 不该口语化）
  脚本/aigc_scan.py                # AI 特征扫描（9 维度，含口语化与破折号密度预警）
```

执行时只读取本目录内部文件，不查找外部安装的 aigc-reduce / humanizer-zh 等 skill。

## 触发与范围

- 触发：用户提出上述任一意图 → 开启本部分并先说明策略，等待用户确认。
- 未触发：不得主动改词；审核定稿的原稿保持冻结。
- 对象：正文与摘要；表格单元格文字、图注可同步处理；**公式、图内文字与图表本体不改**。
- 输入：`PROJECT_ROOT/完整论文-LaTeX/`（LaTeX 源优先作为改写基底）与已冻结的 `完整论文.docx/pdf`。

## 保学术性的总原则（硬底线）

1. 目标是“去掉模板化 AI 痕迹”，不是“写得更随便”；**学术书面语体是硬底线**。
2. 任何改写不得改变：模型/方法/算法名、符号与公式、数值与单位、图表编号与题注、参考文献编号与引用、结论主张、章节结构。
3. 只做**确定性局部替换与句式重构**，禁止整段 AI 全量重写（检测平台对全量重写通常判 100%）。
4. 双版本交付：`完整论文.docx/pdf`（原冻结版不动）+ `完整论文-去AI味版.docx/pdf`；生成 `降重差异审计.md`，逐条记录 原句 → 新句 → 修改类型 → 是否触碰保护片段。

## 执行协议（三轮）

1. **第一轮 减法**：按 `红线与自检.md` 与 `方法库/protected-spans.md` 圈出保护片段；运行 `python <SKILL_ROOT>/references/降重模块/脚本/aigc_scan.py <正文.txt>` 扫描，再对照 `方法库/replacement-tables.md` 逐处确定性替换；每处用不同替代，避免同义轮换与“为降重而降重”。
2. **第二轮 加法（书面特征）**：按 `方法库/positive-style-academic.md` 做句子长短交错与书面推断限定（“一种可能的解释是…”“该结果有待更多样本验证”），每段至多 1 句；不做口语化、不编造原文没有的细节。
3. **第三轮 审计 + 终扫**：对照 `方法库/ai-patterns.md` 与 `红线与自检.md` 逐项自检，再次运行 `aigc_scan.py` 看 9 维度变化；复跑全文门禁（`scripts/paper_check.py`、`equations.py verify-formulas`、公式/图号/表号/数值一致性）；修完提交用户审核。

## 方法取向（明确不采用）

- 不采用口语化、网络用语、情绪词、破折号堆砌等“注入人味”路线：这类写法可能提高机审规避率，但会破坏论文语体、过不了人审（`方法库/detection-principles.md` 的“护栏”段有原理说明）。
- 本模块默认走“学术书面语 + 确定性替换 + 保护片段”路线，语体规范优先于修改率目标。

## 完成判定

- 冻结原稿哈希未变；降重版所有数值/术语/公式/引用与冻结稿一致；`降重差异审计.md` 齐全；全文门禁复跑通过；用户审核通过后才交付。
